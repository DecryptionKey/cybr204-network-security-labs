# CYBR204: Network Security Labs

Labs from **CYBR204 Intro to Computer Networks & Security** at the University at Albany (Spring 2026). The course covers how networks work (protocols, routing, data transfer) with hands-on packet analysis and network design.

## Labs

| # | Lab | Focus |
|---|-----|-------|
| 01 | [Network Infrastructure Assessment & Asset Discovery](labs/01-network-infrastructure-assessment/) | Topology mapping, routing/ARP analysis, Nmap asset inventory |
| 02 | [Transport & Application Layer Traffic Analysis](labs/02-transport-application-traffic-analysis/) | TCP/UDP behavior, cleartext vs encrypted protocols, TLS, rebuilding files from captures |
| 03 | [Layer 2 Network with Spanning Tree](labs/03-layer-2-spanning-tree/) | Root bridge, port states, STP failover |
| 04 | [Layer 3 Network with Dynamic Routing](labs/04-layer-3-dynamic-routing/) | RIPv2 configuration, authentication, convergence after a link failure |

## Research

- [Cognitive Load, Fatigue, and Security Decision-Making](research/cognitive-load-literature-review.md): term-project literature review of five papers on operator stress, burnout, and how cognitive load affects responses to security alerts.

## Tools used
Windows Server, Quagga (RIPv2), Linux bridges (STP), pfSense, PuTTY, Nmap/Zenmap, Wireshark, Tftpd64, netcat
