# CYBR204: Network Security Labs

Labs from **CYBR204 Intro to Computer Networks & Security** at the University at Albany (Spring 2026). The course covers how networks work (protocols, routing, data transfer) with hands-on packet analysis and network design.

## Labs

| # | Lab | Focus |
|---|-----|-------|
| 01 | [Network Infrastructure Assessment & Asset Discovery](labs/01-network-infrastructure-assessment/) | Topology mapping, routing/ARP analysis, Nmap asset inventory |

## Tools used
Windows Server, Quagga, pfSense, PuTTY, Nmap/Zenmap
